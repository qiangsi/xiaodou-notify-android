# 小豆通知（Xiaodou Notify）· Android 原生 App

**小豆通知是「毛豆通知」的无成就轻量独立版**：通知核心能力完全一致，但移除整套成就系统——没有成就定义、进度记录、达成判定，也没有成就入口。适合只想要安静的通知管家、不需要游戏化激励的用户。

- **技术栈**：Kotlin + Jetpack Room + Material 3 + 协程 + ViewBinding
- **版本**：**v1.0.10**（versionCode 11）· 底部导航选中态反馈（填充/描边图标 + 变色） · 最低 Android 8.0（API 26），目标 Android 15（API 35）
- **隐私**：通知内容 AES-256-GCM 加密存本地（密钥在 Android Keystore），零上传；唯一外发通道是用户显式配置的 Webhook
- **包名**：`com.xiaodou.notify`（与毛豆通知不同，可同时安装、数据互不干扰）

| 通知历史 / 搜索 / 倒叙 | ✅ | ✅ |
| 自定义过滤规则 / 离线 AI 骚扰识别 | ✅ | ✅ |
| 验证码保险箱 / 清净周报 / 桌面小部件 | ✅ | ✅ |
| 主题 / 图标切换 / 应用锁 | ✅ | ✅ |
| 离线 Pro 激活（open-core） | ✅ | ✅ |
| 成就分类 / 定义 / 进度 | ✅ | ❌ 未包含 |
| 成就达成判定 / 奖励领取 | ✅ | ❌ 未包含 |
| 底部导航「成就」入口 | ✅ | ❌ 未包含 |

## 目录结构

```
XiaodouNotify/
├── app/src/main/java/com/xiaodou/notify/
│   ├── XiaodouApp.kt          # Application：主题、应用锁、保活、默认规则
│   ├── data/                  # Room 数据库 v2：通知/规则/AI 反馈（无成就表）
│   ├── engine/                # 规则引擎、骚扰评分、动作执行、Webhook
│   ├── listener/              # 通知监听服务、保活、小部件、广播接收器
│   ├── ui/                    # 历史 / 规则 / 分析 / 设置 四个 tab 与各详情页
│   └── util/                  # 权限、应用锁、Pro、主题、偏好等工具
├── app/src/main/res/
│   ├── layout/                # 仅基础通知页面（无成就布局）
│   ├── menu/bottom_nav_menu.xml  # 四个入口，无成就入口
│   └── values/                # 应用名「小豆通知」，无成就字符串
├── app/build.gradle.kts       # applicationId=com.xiaodou.notify，versionCode=7
└── README.md
```

## 更新记录

### v1.0.10 · 底部导航选中态反馈（2026-11-23）

### v1.0.9 · 跨品牌流畅度优化（2026-11-22）
- **切页不再重复加载**：底部四个 tab 的页面改为实例缓存 + 显示/隐藏复用，设置页等大型布局只加载一次，来回切换不再重新解析布局与重复订阅全表数据。
- **历史列表后台计算**：筛选、解密、日期分组、计数全部移到后台线程，主线程只负责渲染；新增解密缓存，滚动与搜索时不再逐条重复解密。
- **列表增量刷新**：用 DiffUtil 只更新变化的条目，替代整表全量刷新，滚动更稳。
- **统计按需查询**：待办等计数改为按 id 分批查询，不再为几个数字读取整张表。
- **数据库补索引**：为常用查询字段补索引，已安装用户下次打开自动生效，无需卸载或迁移数据。
- **诊断开关**：诊断页新增「性能打点」开关（默认关闭），需要排查卡顿时可打开并在 logcat 过滤 `MaodouPerf` 查看耗时。
- versionCode 10，沿用 debug.keystore 可覆盖安装，数据不丢。

### v1.0.8 · 修复解锁面板激活码输入框不可见（2026-11-22）
- **真因**：解锁面板把输入框排在 4 段权益说明、价格、获取码链接、过期提示之后，且整段没有 ScrollView。小屏或大字体下输入框被挤出可见区域，但底部「立即激活」按钮始终可见，用户看不到输入框、直接点激活 → 校验空串 → 弹「激活码无效」，看起来像「没有输入入口」。
- **输入框置顶**：粘贴框与粗体指引「↓ 在这里粘贴激活码」挪到面板最顶部并加边框，打开即可见；获取码入口保留在输入框正下方。
- **整体可滚动**：面板内容用 ScrollView 包裹，小屏 / 大字体都能滚动查看全部内容。
- **空输入兜底**：未输码就点激活，提示「请先粘贴激活码」并自动聚焦唤起键盘，不再误报「无效」。
- versionCode 9，沿用 debug.keystore 可覆盖安装，数据不丢。

### v1.0.7 · 修复 Pro 激活提示与状态不一致（2026-11-22）
- **修复误报**：过期周卡码过去仍被判为有效，导致「激活成功」提示后卡片立刻显示「已到期」；现在校验阶段即按签发时刻 7 天判过期，过期码不再写回激活状态，提示改为「这张周卡已过期，请重新获取新激活码」。
- **补回输入入口**：已激活状态的状态弹窗新增「更换激活码」按钮，续期/换码不再找不到入口；面板在已到期时显示醒目提示且输入框留空。
- **状态同步**：卡片文案改为「激活已到期 · 点此重新输入激活码」，设置页回到前台即刷新，周卡在后台到期也能立刻同步。
- **不影响存量码**：仅调整本地判定逻辑，签发密钥与码格式未变，已发出的有效码继续可用；周卡仍从发码时刻起算 7 天，过期无法续期。
- versionCode 8，沿用 debug.keystore 可覆盖安装，数据不丢。

## 构建

```bash
JAVA_HOME=/path/to/jdk17 ./gradlew assembleRelease
```

公开仓库为 **open-core 社区版**：`util/ProHelper.kt` 是社区占位实现（校验恒不通过），`app/build.gradle.kts` 不注入任何密钥，clone 后可直接编译出完整免费版。需要 Pro 请使用官方发布包并向开发者索取激活码。
